- for long running scripts use tqdm to show a progress bar
- never use `not collection` to see if a collection (list, set, dict, etc.) is empty. Always use len(list) == 0
- never use `if not foo` to check if foo is None. Always use `foo is None`. Do this even if no other falsy value is possible.
- if some error is supposed to stop a process, never catch it, let it bubble, if not print an error log and continue gracefully. Wherever possible use empty array or None value as fallback if error.
